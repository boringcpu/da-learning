```text
titanic
项目背景：
根据泰坦尼克号乘客信息及存活结果，分析影响乘客生存的关键因素，并建立预测模型
分析目标：
预测乘客是否存活，并识别主要影响因素。
数据处理：
- 缺失值分析（Age中位数填充，Cabin缺失严重暂不使用）
- 数值变量分布、偏态及异常值分析
- 特征相关性分析
- 特征与目标变量关系分析
主要发现：
- 女性乘客存活率明显高于男性
- 高等级舱位乘客存活率更高
- Fare存在明显右偏分布
后续优化：
- 对严重偏态变量进行对数变换
- 特征编码及特征工程
- 建立分类模型并进行评估
```

```text
eCommerce
项目背景：
基于电商平台用户行为日志数据，分析用户行为转化路径。
分析目标：
分析用户从浏览到购买过程中的转化情况，并定位主要流失环节。
数据处理：
- 用户行为数据清洗
- 漏斗构建
- 各阶段转化率计算
- 用户分层分析
主要发现：
- 浏览→登录→购买各阶段存在明显流失
- 登录环节转化率下降幅度较大
- 登录环节可能与近期销售表现变化相关
后续优化：
- 分渠道分析用户转化情况
- 分工作日/周末进行对比
- 分用户类型（新老用户）进一步分析
```

```text
Gamelytics
项目背景：
基于线上游戏用户注册及登录行为数据，分析用户留存情况和活跃趋势。
分析目标：
分析用户1日、3日、7日留存率，并观察新增用户和活跃用户变化趋势。
数据处理：
- 注册数据与登录行为数据清洗及关联
- Unix时间戳转换
- 计算每日新增用户及DAU（日活用户）
- 构建留存分析逻辑并计算D1、D3、D7留存率
主要发现：
- 新增用户数与日活用户整体呈增长趋势
- 用户留存率波动较小，整体相对稳定
- 不同注册日期用户留存表现存在一定差异
后续优化：
- 按月或按周进行留存趋势分析
- 构建 Cohort 留存矩阵并可视化
```
